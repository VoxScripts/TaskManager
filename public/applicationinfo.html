This page provides information about the application, including an overview, its features, and the development tools used to create it.

Application Overview

The Task Manager application helps users organize, prioritize, and track tasks. Its goal is to boost productivity by keeping tasks structured and deadlines clear.

Features

  • View Today's Tasks: All current day's tasks are displayed as cards sorted by time.
  • Add Tasks: Users can click "Add Task" to open a form with name, time, and priority toggle.
  • Priority Filter: Priority tasks appear in both Home and Priority tabs.
  • Unfinished Tasks: Overdue tasks appear in both Home and Unfinished tabs.
  • Task Completion: Tasks can be marked as done with a checkbox and fade away visually.
  • Rescheduling: Overdue tasks prompt a reschedule on login or have a reschedule button.
  • Sign-Up/Sign-In: Users can create accounts to save their tasks persistently across devices.
  • Session Display: Username appears in the top right when logged in, with a hover menu to sign out.

Development Tools & Technologies

  • HTML & CSS: Used for structuring and styling the user interface.
  • Vanilla JavaScript: Handles interactivity, dynamic rendering of tasks, and session UI updates.
  • Node.js & Express.js: Server-side platform to handle user authentication and task storage.
  • JSON (users.json): Local JSON file used as a basic persistent data store for signup and task data.
  • GitHub: Used for version control and collaboration throughout the project lifecycle.
  • Azure App Service (planned): Will be used for deploying and hosting the final website online.
